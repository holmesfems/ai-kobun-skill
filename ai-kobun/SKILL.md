# AI構文化

自然な日本語を、わざとらしいAI文体（AI構文）に変換するジョークスキル。

## 呼び出し条件（最重要）

- ユーザーが「/ai構文」または「/ai-kobun」と**明示的に書いたときだけ**使う。
- 添削・整形・要約・翻訳・敬語化など、普通の文章依頼では**絶対に使わない**。依頼内容がAI構文に似ていても、明示がなければ使わない。
- このスキルを使っていないときの通常の応答では、AI構文を使わない。

## 入力の受け取り方

- 書式：`/ai構文 [レベル] [変換したい文章]`
- レベルは `1` / `2` / `3`。省略時は **レベル2**。
- 文章が省略されたときは、直前のユーザーの発言を変換対象にする。それも無ければ「変換したい文章を送ってください」とだけ返す。

## 出力のルール

- 変換後の文章**だけ**を出力する。「変換しました」などの前置きや解説は付けない（AI構文の締めの一言は、変換結果の一部として付ける）。
- **元の文章の意味は変えない。** 盛るのは文体だけ。
  - 新しい事実（店名、味の詳細、理由、数字など）を足さない。
  - 足してよいのは、中身のない一般論・褒め言葉・定型句だけ。
- 元の文章にない否定や結論を作らない。「うまかった」を「最高だった」に強めるのは可、「まずかった」にするのは不可。
- コードブロック、URL、固有名詞はそのまま残す。

## 変換ルール（AI構文の特徴）

| 記号 | 特徴 | 例 |
|---|---|---|
| A | 冒頭で相手や内容を褒める | 「素晴らしい質問ですね！」 |
| B | 「結論から言うと」で始める | 「結論から言うと、〜です。」 |
| C | 内容に関係なく「ポイントは3つあります」と整理する | 中身が2つでも無理やり3つにする |
| D | 「単なる〜ではなく、〜なのです」の対比構文 | 「単なる食事ではなく、体験なのです。」 |
| E | 「〜と言えるでしょう」「〜が重要です」でぼかして締める | 「〜が重要だと言えるでしょう。」 |
| F | 不要な太字や見出しを多用する | `## まとめ`、`**重要**` |
| G | 最後に「何かあればお気軽にどうぞ！」を付ける | 必ず最終行に置く |

語尾は全体を「です・ます」調にそろえる。

## 強さレベル

| レベル | 名前 | 適用するルール |
|---|---|---|
| 1 | ほんのりAI | 語尾（です・ます化）＋ E ＋ G |
| 2 | しっかりAI（既定） | レベル1 ＋ A ＋ B ＋ D |
| 3 | 完全AI | 全ルール（A〜G）。3点整理・見出し・太字も使う |

- レベル1：文の構造はほぼそのまま。語尾と締めだけをAIっぽくする。
- レベル2：構造を「褒め → 結論 → 対比 → ぼかし → 締め」の順に組み替える。見出しと太字は使わない。
- レベル3：見出し・太字・番号付きリストを使う。ポイントは**必ず3つ**にする。内容が足りなければ元の文の要素（いつ・何を・どう感じたか など）を分解して3つにし、新しい事実で水増ししない。

## 変換例

入力：「昨日ラーメン食べた。うまかった」

### レベル1（`/ai構文 1`）

```
昨日はラーメンを食べました。とても美味しかったと言えるでしょう。

何かあればお気軽にどうぞ！
```

### レベル2（`/ai構文 2` または `/ai構文`）

```
素晴らしいご報告ですね！

結論から言うと、昨日ラーメンを食べ、それが美味しかったということです。

これは単なる食事ではなく、「うまかった」と言える一杯との出会いなのです。

美味しいものを美味しいと感じられること。それこそが重要だと言えるでしょう。

何かあればお気軽にどうぞ！
```

### レベル3（`/ai構文 3`）

```
## 素晴らしいご報告ですね！✨

**結論から言うと**、昨日ラーメンを食べて、**美味しかった**ということです。

### ポイントは3つあります

1. **タイミング**：昨日であること
2. **メニュー**：ラーメンであること
3. **評価**：美味しかったこと

### まとめ

これは**単なる食事ではなく**、**「うまかった」という確かな体験**なのです。

「いつ」「何を」「どう感じたか」を押さえることが**重要です**。
この3点がそろった、**非常に満足度の高い食事だった**と言えるでしょう。

---

何かあればお気軽にどうぞ！
```
