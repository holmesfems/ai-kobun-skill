# AI構文化（ai-kobun）

> **⚠️ これはジョークスキルです。**
> 業務効率は1ミリも上がりません。むしろ文字数が増えて下がります。

あなたの書いた素朴な日本語を、**どこかで見たことのあるAIっぽい文体**（いわゆる「AI構文」）に変換する Claude 用スキルです。

「昨日ラーメン食べた。うまかった」が、なぜか**3つのポイント**に整理されて返ってきます。

## 結論から言うと

このスキルは、**単なる文体変換ではなく、AIへのささやかなツッコミなのです。**

……という具合です。

## インストール

`ai-kobun` フォルダを、Claude Code のスキルディレクトリにコピーしてください。

```bash
# 自分専用（全プロジェクトで使う）
cp -r ai-kobun ~/.claude/skills/

# 特定のプロジェクトだけで使う
cp -r ai-kobun <your-project>/.claude/skills/
```

## 使い方

```
/ai構文 [レベル] [変換したい文章]
```

| 呼び出し | 強さ | 中身 |
|---|---|---|
| `/ai構文 1 〜` | ほんのりAI | 語尾と締めだけAI |
| `/ai構文 2 〜` | しっかりAI | 褒め・結論ファースト・対比構文 |
| `/ai構文 3 〜` | 完全AI | 全部のせ。3点整理、見出し、太字も |
| `/ai構文 〜` | （レベル2） | レベル省略時はしっかりAI |

文章を省略すると、直前の自分の発言を変換します。

> **📝 補足：** スキル名の仕様上、Claude Code のスラッシュコマンドとしては `/ai-kobun` になります。
> メッセージ中に「/ai構文」と書いた場合は、Claude がスキルの説明を読んで呼び出します。

### 呼び出し条件について（大事）

このスキルは **「/ai構文」と明示したときだけ** 動きます。

「この文章を添削して」「要約して」「丁寧にして」といった普通の依頼では動きません。
真面目なメールを頼んだのに「素晴らしい質問ですね！」から始まったら、事故だからです。

## 変換ルール

AI構文の特徴を、以下の7つに整理しました（7つです。3つではありません）。

1. 冒頭で相手や内容を褒める（「素晴らしい質問ですね！」）
2. 「結論から言うと」で始める
3. 内容に関係なく「ポイントは3つあります」と整理する
4. 「単なる〜ではなく、〜なのです」の対比構文
5. 「〜と言えるでしょう」「〜が重要です」でぼかして締める
6. 不要な太字や見出しを多用する
7. 最後に「何かあればお気軽にどうぞ！」を付ける

ただし、**元の文章の意味は変えません。** 盛るのは文体だけです。
「うまかった」が「店主のこだわりが光る濃厚豚骨スープ」になったりはしません。

## 変換例

入力：

```
昨日ラーメン食べた。うまかった
```

### レベル1：ほんのりAI

```
昨日はラーメンを食べました。とても美味しかったと言えるでしょう。

何かあればお気軽にどうぞ！
```

まだ人間のふりができる段階です。

### レベル2：しっかりAI

```
素晴らしいご報告ですね！

結論から言うと、昨日ラーメンを食べ、それが美味しかったということです。

これは単なる食事ではなく、「うまかった」と言える一杯との出会いなのです。

美味しいものを美味しいと感じられること。それこそが重要だと言えるでしょう。

何かあればお気軽にどうぞ！
```

誰も何も質問していないのに褒められます。

### レベル3：完全AI

```
## 素晴らしいご報告ですね！✨

**結論から言うと**、昨日ラーメンを食べて、**美味しかった**ということです。

### ポイントは3つあります

1. **タイミング**：昨日であること
2. **メニュー**：ラーメンであること
3. **評価**：美味しかったこと

### まとめ

これは**単なる食事ではなく**、**「うまかった」という確かな体験**なのです。

「いつ」「何を」「どう感じたか」を押さえることが**重要です**。
この3点がそろった、**非常に満足度の高い食事だった**と言えるでしょう。

---

何かあればお気軽にどうぞ！
```

元は2文、15文字です。
